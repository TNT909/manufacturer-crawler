# 企业工商信息核验工作流

本目录提供一套可复用的国内企业工商信息核验工作流，用于投标前的供应商/制造商资质核查。

## 数据源

天眼查微信小程序逆向接口 `api9.tianyancha.com`，方案源自开源项目
`bouxin/company-crawler`（2026-10-10 实测可用，接口当前不校验 token）。

一次搜索调用即可返回：注册资本、存续状态、统一信用代码、法定代表人、
成立日期、省份、地址、电话、历史名称、经营范围等。

## 使用方法

```bash

PYTHONPATH= "C:/Users/gogoo/AppData/Local/Programs/Python/Python313/python.exe" tyc_verify.py 名单.xlsx

# json 名单（[{"name": "..."}, ...] 或 ["名1", "名2"]）
PYTHONPATH= "C:/Users/gogoo/AppData/Local/Programs/Python/Python313/python.exe" tyc_verify.py 名单.json
```

输出两个文件（与输入同名）：
- `xxx_tyc.json` — 结构化原始结果（含 http 状态、匹配详情）
- `xxx_tyc.xlsx` — 美化交付表（深蓝表头、存续状态着色、冻结表头）

> 注：Windows 上必须加 `PYTHONPATH=` 清空，否则会误用 PATH 上损坏的 hermes venv（PIL 坏、无 pip）。完整 Python 路径见 `tyc_verify.py` 顶部说明或直接运行脚本（脚本内已固定）。

## 核验字段与判定规则

### 直接返回（权威）
- **注册资金** `regCapital`：如 `5000万美元`、`600万人民币`，附数值与币种解析
- **存续状态** `regStatus`：存续 / 在业 / 注销 / 吊销
- 统一信用代码、注册号、法定代表人、成立日期、地址、电话、经营范围

### 企业性质（组合规则推断，非权威）
| 判定 | 依据 |
|---|---|
| 国有 | tagList/orgTypeName 含「国有/央企/国企」 |
| 外资 | 含「外商/外资/中外合资/港澳台」 |
| 外资(外币) | 注册资本为 美元/港元/欧元 |
| 私营 | 其余（排除法） |

> ⚠️ 复杂股权（国资间接控股）单靠此规则判不准。重大投标务必人工复核股东结构或对照营业执照。

## 未匹配处理

脚本自动两级匹配：
1. 全名搜索
2. 未命中则去括号别名用核心词重试（如「中国精美铝业（精美JM）」→「中国精美铝业」）

纯英文名/简称仍可能 `total=0`，需先转中文全称或补「有限公司」后缀。

## 稳定性与合规

- 每请求间隔 0.8s，失败重试 3 次（间隔 2s）
- 勿高频并发——虽当前不校验 token，仍可能被风控
- token 失效时按 `bouxin/company-crawler` 说明走代理重新获取
- **逆向接口，个人自用性质，勿公开部署/商用转售**；重大决策结果应交叉验证官方源

## 实测基线（2026-10-10）

对 82 家铝管制造商：命中 72/82（88%）。未命中 10 家均为简称/英文名/括号别名问题，换核心词可救回。
