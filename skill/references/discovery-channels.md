# 厂商发现渠道清单（发现模块 · 实测底稿）

> 发现模块范围：只列"能挖到厂商+企业独立官网"的渠道与发现期采集要求。
> 工商核验 → `verification-channels.md`；英文站/产品形态实测 → `website-content-verification.md`；
> 海关/贸易背景数据是独立模块，不列入发现渠道。
> 可达性为 urllib 实测（HTTP 状态码，Mozilla UA），渠道状态会变——本表只作底稿，
> 被问"有哪些渠道"前必须先实测探测再答（方法见文末），不要把本表当答案直接罗列。

## 一手发现（直接挖到企业+独立官网）

### 搜索引擎（核心）

| 引擎 | 实测 | 说明 |
|------|------|------|
| 百度 | 200 | 中文品名+官网/厂家限定词最有效 |
| Bing | 200 | 中英文均可；找"XX展 展商名录"首选 |
| 搜狗 | 200 | 可搜微信生态内容 |
| 360 | 200 | 备选 |
| 神马 | 200 | 移动端备选 |

用法：中文品名+限定词组合（民营/有限公司/官网/厂家）。试点实测"复合绝缘子"3组查询→24条原始结果→约10家有独立官网的企业。小样验证后按发现的企业类型迭代扩词，不必先建庞大关键词表。

## 按品类挖掘

### 行业垂直站 / 协会名录

每品类有对应垂直门户（阀门/绝缘子/电力金具各有）和行业协会；会员名录常为 PDF，需提取企业名后逐个核实官网。**按品类定制，需建品类 → 渠道映射**。

### 展会参展名录

展会官网常不可达(000)，改用 Bing 搜"XX展 展商名录"提取企业名。

## 不列入发现渠道

- 海关/贸易数据（UN Comtrade / Panjiva / ImportYeti）：仅国家级汇总或需付费订阅，定位不到具体企业 → 独立品类背景模块
- 工商核验平台（爱企查/企查查/天眼查）：属核验模块 → `verification-channels.md`

## 可达性探测方法

在 execute_code 内核用 urllib（Mozilla UA，timeout≈12s）逐源探测，取真实 HTTP 状态码。不要用本机 terminal curl：该主机终端流量被代理拦截，`-o /dev/null` 下 curl (23) 写入报警会掩盖真实状态。反爬行为（环境检测页/验证码）只有真实浏览器能观察到，探测只能证明"可达"不能证明"可抓"。
